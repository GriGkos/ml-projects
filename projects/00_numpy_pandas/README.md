# Project 00: NumPy and Pandas

Вводный проект по базовой практике с `pandas` и `NumPy`.

## Состав работы

- [00_numpy_pandas.ipynb](./00_numpy_pandas.ipynb)
- `data/credit_data.xlsx`

## Что сделано в ноутбуке

1. Данные загружены из Excel-файла в `DataFrame`.
2. Выведена размерность таблицы.
3. Показаны первые 5 строк.
4. Показаны последние 5 строк.
5. Получена общая информация о `DataFrame`.
6. Удалён столбец `client_id`.
7. Выполнена группировка по `recent_salary`.
8. Найдены записи, где `recent_salary == 'no data'`.

## Комментарий

В столбце `recent_salary` встречаются не только числа, но и текстовое значение `no data`, поэтому для числовой агрегации этот столбец лучше предварительно приводить к числовому типу через `pd.to_numeric(..., errors='coerce')`.

## Как открыть

Открой ноутбук `00_numpy_pandas.ipynb` в Jupyter Notebook или VS Code и выполни ячейки сверху вниз.
