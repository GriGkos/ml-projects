# Project 01: ML Bricks

Учебный проект с тренировкой базовых кирпичиков ML-пайплайна на датасете `load_breast_cancer`.

## Состав работы

- [01_ml_bricks.ipynb](./01_ml_bricks.ipynb)

## Что сделано в ноутбуке

1. Реализован стратифицированный train/test split.
2. Выполнена импутация пропусков без утечки данных.
3. Реализовано One-Hot кодирование категориального признака.
4. Посчитаны основные метрики классификации вручную.
5. Сравнены ROC-AUC и dummy accuracy при дисбалансе классов.
6. Выполнена стратифицированная кросс-валидация.
7. Подобран гиперпараметр `C` через `GridSearchCV`.
8. Найдены 3 самых важных признака по `DecisionTreeClassifier`.

## Результат

Все автопроверки в ноутбуке пройдены.

## Как открыть

Открой ноутбук `01_ml_bricks.ipynb` в Jupyter Notebook или VS Code и выполни ячейки сверху вниз.
