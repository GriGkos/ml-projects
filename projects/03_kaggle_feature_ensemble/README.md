# Elo Merchant Category Recommendation

Проект для соревнования Kaggle [Elo Merchant Category Recommendation](https://www.kaggle.com/competitions/elo-merchant-category-recommendation). Задача - предсказать показатель лояльности `target` по атрибутам карт и истории транзакций. Метрика соревнования - RMSE: чем меньше значение, тем лучше.

## Результат Kaggle

Итоговый файл `submission_xgboost_seed_bagging.csv` получил public RMSE **3.69682** и private RMSE **3.61029**. По скачанному private leaderboard это **132-е место из 4 111**, или **топ 3.21%**. Граница топ-5% равна `3.61179`, поэтому результат вошёл в топ-5%.

## Подход

1. Проведён EDA исходных таблиц, целевой переменной, транзакций и продавцов.
2. Транзакции из historical и new периодов агрегированы до уровня `card_id`.
3. Построены признаки активности, сумм покупок, категорий, рассрочки, разнообразия продавцов, временной динамики и различий между периодами.
4. Группы признаков последовательно сравнивались в абляционном эксперименте.
5. Обучены и настроены `LightGBM`, `XGBoost` и `CatBoost`; также добавлены `DummyRegressor` и `RidgeCV` как простые baseline.
6. Для проверки моделей использована пятифолдная стратифицированная OOF-валидация по индикатору `target < -30`.
7. Проверены target encoding, взвешенный blend, Ridge stacking и отдельная корректировка экстремального сегмента.

## Сравнение моделей

| Модель | OOF RMSE |
| --- | ---: |
| DummyRegressor | 3.850497 |
| RidgeCV | 3.842995 |
| LightGBM с подбором параметров | 3.661095 |
| XGBoost с подбором параметров | 3.642479 |
| CatBoost с подбором параметров | 3.645502 |
| XGBoost с bagging по трём seed | 3.640658 |
| Взвешенный blend | 3.640409 |
| Ridge stacking | 3.640144 |

Стэкинг дал минимальный OOF RMSE, но его преимущество над XGBoost bagging составляет всего `0.000514`. Бутстрэп-разность неустойчива и включает ноль, поэтому в качестве итоговой модели выбран более простой и воспроизводимый `XGBoost` с усреднением трёх seed.

## Что сработало

- Добавление агрегатов по historical и new транзакциям существенно улучшило качество относительно признаков карт.
- Блок устойчивых признаков покупок и календарной активности оказался лучшим в абляции.
- Подбор параметров XGBoost улучшил OOF RMSE с `3.655293` до `3.642479`.
- Усреднение XGBoost по трём seed дополнительно улучшило результат до `3.640658`.

## Что не сработало

- Target encoding не улучшил настроенный XGBoost: `3.642831` против `3.642479`.
- Корректировка экстремального сегмента ухудшила общий RMSE, хотя снизила ошибку на самом хвосте target.
- Сложные ансамбли не дали устойчивого выигрыша, достаточного для выбора вместо XGBoost bagging.
