# Репозиторий ML-проектов

Каждый учебный проект оформляется в отдельной ветке. Текущая ветка содержит решение для соревнования Kaggle **Elo Merchant Category Recommendation**.

## Содержимое

- `projects/03_kaggle_feature_ensemble/` - полный проект: EDA, feature engineering, обучение моделей, ансамблирование и итоговый сабмит;
- `projects/03_kaggle_feature_ensemble/notebooks/solution.ipynb` - основной ноутбук с последовательностью экспериментов;
- `projects/03_kaggle_feature_ensemble/README.md` - описание подхода, результатов и инструкция по воспроизведению.
